## What the tutorials teach, with where it is said

| Rule | Source (transcript file) |
|---|---|
| Timing is the gap between keyframes; spacing is the easing between them. Change the curve, not the keyframe distance, to change feel | HpVtzOtaHlg |
| An object entering the frame should already be moving: flatten the first handle so there is no ease-in, then ease hard into the landing | HpVtzOtaHlg |
| An impact keyframe gets no deceleration (break the handle), the settle after it gets a long ease | HpVtzOtaHlg |
| Overshoot: scale to 110-120 about 4 frames after the main key, then settle back | HpVtzOtaHlg |
| Anticipation: pull the first handle below the zero line so the value dips before it goes | HpVtzOtaHlg |
| Value graph for shape of motion, speed graph for how hard it hits | xM9w0SSpgtc, HpVtzOtaHlg |
| 60 fps is what makes "Apple smooth"; motion blur on every moving layer | cpQzSKuEAkM |
| Text reveals word by word by staggering opacity keys; range-selector ease high -50 / ease low 100 on a ramp shape | cpQzSKuEAkM |
| Subtext enters later than the headline (offset the layer) | cpQzSKuEAkM |
| Drop shadows stay very subtle, around 15-20% opacity with high softness | cpQzSKuEAkM, Zfx5oL3pPmk |
| Backgrounds: four-colour or radial gradients in the scene's own colours; add noise/jitter so gradients do not band | cpQzSKuEAkM, Jccbzpicst8 |
| Stagger repeated elements every 4-6 frames | vye0_xIG5HY |
| Scenes about 10 s each at 30 fps in a long explainer; short promos cut far faster | vye0_xIG5HY |
| Hold keyframes for a hard switch (a screen swap), then ease the next move | Zfx5oL3pPmk |
| 3D layers moved toward the camera give depth without real 3D | cpQzSKuEAkM |
| Sound effects on every action; the music carries the cut rhythm | cpQzSKuEAkM |
