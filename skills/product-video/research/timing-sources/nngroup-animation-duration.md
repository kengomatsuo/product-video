# Nielsen Norman Group — Executing UX Animations: Duration and Motion Characteristics

URL: https://www.nngroup.com/articles/animation-duration/

Fetched: 2026-09-24 (WebFetch, direct)

## Notes (all numbers primary-sourced from the article)

- **Simple feedback animations** (checkbox, toggle): ~100 ms total.
- **Substantial screen changes** (modal moving into view): 200–300 ms.
- **General range for most UI animations**: 100–500 ms, scaled by complexity and distance traveled; 100–400 ms is the practical sweet spot.
- **400 ms** = very slow, reserve only for big movements across large screens.
- **500 ms** = the point where animations start to feel like "a real drag" — annoying, not delightful.
- **Entry vs. exit asymmetry**: objects entering the screen should get a subtly *longer* duration than the same object exiting (example given: 300 ms in, 200–250 ms out) — entering needs to be noticed, exiting just needs to get out of the way.
- Explicit distance/size scaling rule: the further an element travels, the more duration it needs to avoid feeling jarring; there's no single formula, but duration should visibly track distance.

## Quote (under 15 words)

"the duration of most animations should be in the range of 100–500 ms"
