## Patterns observed (with files)

1. **Single device, gradient background, no clutter** is the dominant hero shot for app promo videos — see `dribbble-umairkhan-01/02`, `dribbble-viktoriialozovska-03/04`, `dribbble-arupbaroi-05/06`. None of these put more than one phone on screen at once.
2. **Studio house style repeats across a whole portfolio** — TimeFrame (`dribbble-timeframe-07/08/09/10/44/45`) and Purrweb (`dribbble-purrweb-30-35`) both reuse one background/lighting setup across many client videos, which is cheaper to reproduce than a bespoke look per video.
3. **SaaS explainer videos follow a fixed beat structure**: problem/context screen, then a dashboard reveal, then 2-3 feature close-ups, then a CTA card — clearest in `dribbble-whatastory-17-21` and `dribbble-ramg-64/65`.
4. **App Store preview "screenshot set" compositions are built from repeatable templates**, not one-off layouts — the Val Pieŭnioŭ (`dribbble-valpieuniou-69/70/71/73`) and Pierre-Olivier (`dribbble-pierreolivier-72/74/75`) sets each reuse one caption-and-frame template across many different apps, swapping only the screenshot and headline.
5. **Restaurant/POS demos put the phone or tablet at an angle with the ordering flow mid-interaction** (a finger or cursor implied by a highlighted row), not a static idle screen — see `dribbble-shohag-46/47`, `dribbble-alfianramadhan-48/49`, `dribbble-agensip-77`.
6. **Keyboard-extension UI is rarely shown in motion on Dribbble** — only one true keyboard-interaction prototype turned up (`dribbble-selin-50/51`, made in ProtoPie, not a real product); everything else for "keyboard app" is onboarding/paywall stills (`dribbble-mohammadali-83/84/85`), so Cutling's keyboard-in-use footage will need to come from a real device recording, not from Dribbble references.
7. **Browser-extension promos frame the browser chrome itself**, not just the popup — `dribbble-impactframes-52-55` and `dribbble-aleksandrsubbotin-56/57` both keep visible tabs/toolbar around the extension UI so viewers immediately read it as "in Chrome," relevant for Undirect.
8. **Data-heavy SaaS promos lean on animated charts/counters rather than screenshots** — `dribbble-blahomyrpopok-36/37/42/43` show numbers ticking up and bars growing rather than a static dashboard screenshot, worth considering for solute's reporting features.
